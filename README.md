# lucabaroncini.tech

Il sito di [Luca Baroncini](https://lucabaroncini.tech), Chief AI Officer in [Net7](https://www.netseven.it): idee su AI applicata, agenti e RAG, con le prove a favore e contro.

## Stack

- [Astro](https://astro.build) 5 + MDX
- Tailwind CSS v4
- Cloudflare Workers (asset statici)

## Comandi

```sh
npm install
npm run dev      # server di sviluppo
npm run build    # build statica in dist/
npm run preview  # anteprima della build
```

Le idee sono in `src/content/blog/`, in MDX.
